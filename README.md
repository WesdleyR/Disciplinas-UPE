# Disciplinas UPE

Programa desktop desenvolvido em Python e PySide6 para auxiliar estudantes da Universidade de Pernambuco (UPE) no planejamento da graduação.

## Funcionalidades

- ✅ Marcar disciplinas já cursadas
- 📊 Acompanhar o progresso geral do curso
- 📚 Visualizar pré-requisitos e co-requisitos
- 🔍 Pesquisar disciplinas por nome, código ou período
- 💾 Salvar o progresso automaticamente

Desenvolvido com Python, PySide6 e JSON para armazenamento local dos dados.
